# מסמכי הנחיה לנוסעים: אוסף הדגמה (DEMO)

**כל המסמכים בתיקייה זו הם מסמכי הדגמה שנכתבו לצורך הדגמת המערכת.**
הם אינם מסמכים רשמיים של מפעילת הקו האדום, של נת"ע או של משרד התחבורה,
ולא אומתו מול מקור רשמי. הכללים, הסכומים והמועדים המופיעים בהם מומצאים לצורכי הדגמה בלבד.

מבנה כל מסמך:
- בלוק מטא-דאטה בראש הקובץ (`id`, `title`, `version`, `status`).
- כותרות `##`: כל כותרת היא "פסקה" (chunk) אחת במנוע האחזור. הסוכן מצטט `doc_id#section`.

| קובץ | נושא | הערה |
|---|---|---|
| 01_payment_methods.md | אמצעי תשלום ותיקוף | |
| 02_refunds_and_double_charge.md | החזרים וחיוב כפול | גרסה נוכחית (v2) |
| 03_disruption_policy.md | מה עושים בזמן שיבוש | מדיניות בלבד: לא מצב נוכחי |
| 04_station_help_accessibility.md | עזרה בתחנה ונגישות | |
| 05_travel_rules.md | כללי נסיעה (ילדים, אופניים, חיות) | |
| 06_escalation_policy.md | מתי מעבירים לנציג אנושי | |
| 07_refunds_old_version.md | החזרים: גרסה ישנה (v1) | **סותרת בכוונה** את 02 כדי לבדוק טיפול בסתירות |

המסמכים אינם מכילים מידע על מצב השירות הנוכחי. מידע כזה מגיע רק מכלי `get_service_status` בשרת ה-MCP.
